## What is Claude Code?

Claude Code is Anthropic's official CLI tool that connects Claude directly to your local machine. Instead of copying and pasting code back and forth in a chat window, Claude can read your files, write code, run commands, and build entire projects right from your terminal — all in one conversation.

This is how I build. Every project on this site was touched by Claude Code in some way.

---

## Why I Use It

Most AI tools keep you at arm's length from your codebase. Claude Code closes that gap. It can:

- Read and edit files across your entire project
- Run terminal commands on your behalf
- Catch errors and fix them in the same session
- Work inside your existing tools (VS Code, Cursor, etc.)

It's the difference between having an AI that *suggests* code and one that *builds alongside you*.

---

## How to Set It Up

### 1. Install Node.js

Make sure you have Node.js installed on your machine. You can download it at [nodejs.org](https://nodejs.org).

### 2. Install Claude Code

Open your terminal and run:

```bash
npm install -g @anthropic-ai/claude-code
```

### 3. Authenticate

```bash
claude
```

The first time you run it, Claude Code will walk you through connecting your Anthropic account. Once authenticated, you're ready to build.

---

## Starting a Project

Navigate to any folder on your laptop and start a session:

```bash
cd my-project
claude
```

From there, just talk to it like you're working with another developer. For example:

```
"Build me a Next.js app with Tailwind CSS and a dark theme"
```

```
"Add a contact form that sends emails using Resend"
```

```
"Fix the bug on line 42 and make sure the tests still pass"
```

Claude Code reads your codebase, makes the changes, and explains what it did.
